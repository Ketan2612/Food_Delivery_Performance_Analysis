## 📊 Project Overview

**Food Delivery Performance Analysis** is an end-to-end data analytics project designed to analyze operational factors affecting food delivery performance.

The objective of this project is to identify key patterns and insights from delivery data such as:

* Impact of **traffic conditions**
* Effect of **distance on delivery time**
* Performance comparison across **vehicle types**
* Influence of **weather conditions**
* Distribution of **order types**

The project demonstrates the full data analytics workflow including **data cleaning, exploratory data analysis, SQL-based business analysis, and interactive dashboard creation using Power BI**.

# 🔄 Project Workflow

## 1️⃣ Data Collection

The dataset was obtained from **Kaggle** containing delivery operational data such as:

* Delivery partner information
* Traffic conditions
* Weather conditions
* Distance between restaurant and customer
* Order types and vehicle types

---

## 2️⃣ Data Cleaning (Python)

The raw dataset contained several issues including:

* Missing values
* Invalid records
* Inconsistent formatting
* Outliers and incorrect values

Data cleaning steps included:

* Handling missing values
* Correcting inconsistent categorical values
* Fixing invalid numerical values
* Standardizing column formats
* Converting columns to appropriate data types

Output: **Cleaned dataset exported as CSV**

---

## 3️⃣ Exploratory Data Analysis (EDA)

Exploratory analysis was performed using Python to understand patterns and relationships within the dataset.

Key analyses included:

* Delivery time distribution
* Traffic condition analysis
* Distance vs delivery time relationship
* Vehicle performance comparison
* Weather impact on delivery operations
* Delivery partner ratings analysis

---

## 4️⃣ SQL Business Analysis

SQL queries were written to extract actionable insights from the cleaned dataset.

Example analyses performed using SQL:

* Average delivery time
* Orders distribution by traffic level
* Vehicle performance comparison
* Weather impact on delivery efficiency
* Most popular order types
* Delivery partner rating analysis

These queries simulate real-world **business intelligence analysis performed by data analysts**.

---

## 5️⃣ Power BI Dashboard

An interactive dashboard was created to visualize the insights derived from the analysis.

---

# 📈 Key Insights

Some major insights derived from the analysis:

* **High traffic conditions significantly increase delivery time**
* Delivery time has a **strong positive relationship with distance**
* Certain **vehicle types are more efficient for faster deliveries**
* **Weather conditions influence delivery performance**
* Some **order types are significantly more common than others**

These insights can help food delivery platforms **optimize delivery operations and improve efficiency**.
